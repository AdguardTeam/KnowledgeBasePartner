## Distributor API: automate license management

The Distributor API lets you [manage AdGuard licenses](/reseller/license-management) from your own systems, without the [Partner Portal](/getting-started/partner-portal-overview). For example, your store can generate a license key automatically when a customer pays, and block it when they ask for a refund.

## What the API can do

- Generate license keys for AdGuard Ad Blocker and activation codes for AdGuard VPN, AdGuard DNS, and AdGuard Mail, one at a time or in batches
- Check whether a key or code is activated and get information about its license
- Block or unblock keys, codes, and licenses
- Renew licenses by license key or by activation code

For the full list of methods and parameters, and for the renewal conditions, see the [Distributor API documentation](https://distributor.adguard.com/api.html).

## Who can use the API

We give API access to high-volume resellers under a contract. To ask for access, email us at [b2b@adguard.com](mailto:b2b@adguard.com). Tell us about your sales volume and how you plan to use the API.

See [Prepaid vs postpaid](/reseller/prepaid-vs-postpaid).

## Frequently asked questions

### Can prepaid resellers use the API?

API access is usually available to high-volume resellers with a contract. Email us at [b2b@adguard.com](mailto:b2b@adguard.com) to discuss your case.

### Where is the API documentation?

At [distributor.adguard.com](https://distributor.adguard.com/api.html).

### Can I renew licenses through the API?

Yes. You can renew AdGuard Ad Blocker licenses by license key, and AdGuard VPN, AdGuard DNS, and AdGuard Mail licenses by activation code. An activation code can be renewed only after it’s activated and if renewal is allowed for it. Each invoice ID can be used for only one renewal.

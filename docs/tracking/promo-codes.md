## Promo codes for affiliates: how to get one and how it works

A promo code gives your audience a discount on AdGuard products and credits the sale to you, even if the customer never clicks your link. You request codes in the AdGuard Partner Portal, and each code works for six months.

:::note

To request a promo code, you need an affiliate account in the AdGuard Partner Portal. See [How to sign up](/getting-started/sign-up-affiliate).

:::

## How to request a promo code

1. In the left menu of the Partner Portal, click *Promo tools*.

1. In the *Promo codes* block, click *Request promo code*.

    <!-- Screenshot: ![Promo codes block in the AdGuard Partner Portal with the Request promo code button](/img/tracking-promo-codes-request-button.webp) -->

1. Select the products you need codes for.

1. In *URL of your website, blog, or social media page*, enter the place where you’ll share the code.

1. In *Campaign description*, describe how you’ll promote AdGuard. For example: one post and five stories about VPN pros and cons, with the code at the end of the post.

1. Optional: in *Comment*, suggest the text of your code, such as YOURNAME30. Short codes are easier to remember and type.

1. Click *Send*.

    <!-- Screenshot: ![Request promo code window with product options and campaign description fields](/img/tracking-promo-codes-request-form.webp) -->

You’ll see *Ticket #… created*. Your request becomes a support ticket, and we’ll contact you there to discuss the details. When your code is ready, it appears in *Promo codes*.

Before you request a code, read Section 7 of the [Terms and Conditions](https://adguardpartner.com/en/terms-and-conditions.html). It lists what you can and can’t do with promo codes.

## What you see on the code card

Each code you get has its own card in *Promo codes*:

- *Start date* and *End date*: the code works only between these dates.
- *Discount*: the discount that customers get.
- *Product*: the product the code applies to. *All products* means the code works for every product.
- *Usage*: how often the code has been used.
- A checkout link with your partner ID and code already added. Click *Copy link* to copy it.

## How to share your code

You can share the code in three ways:

- **The code itself.** Customers enter it in the promo code field at checkout on our website. This works well in videos, podcasts, and offline.
- **The checkout link from the code card.** The discount is already applied when the page opens.
- **A promo page with your code.** Add `&promoCode=YOURCODE` to your promo page link, for example `https://adguard-vpn.com/promotion.html?aid=YOUR_ID&promoCode=YOURCODE`. The discount will be displayed on the page.

Promo codes work only on our websites. AdGuard apps for iOS don’t have a promo code field, so customers on iPhone and iPad should buy on our website and then log in to the app with the same email address.

## How sales with your code are credited

When a customer pays with your promo code, the sale is credited to you. The customer doesn’t need to click your link first.

Your promo code also wins over links. If the customer installed the app through another affiliate’s link but paid with your code, the sale goes to you. It works the other way around too: if a customer you referred pays with another affiliate’s code, the sale goes to that affiliate.

Renewals of a subscription bought with your code are credited to you as well.

Sales made with a promo code aren’t tied to a subaccount. In reports by subaccount, you’ll find them under *No subaccount*. For details on how we credit sales, see [How sales are credited](/tracking/cookie-window).

Your commission is calculated from the price the customer actually paid, after the discount. See [How your commission is calculated](/earnings/commission-calculation).

## How long a code works

A code is valid for six months from the day we issue it. You’ll find the exact dates on the code card.

When a code expires, we can’t extend it. Request a new code and replace the old one everywhere you published it. Otherwise, customers who try the old code will see an error at checkout.

## Promo codes and sales on our website

A promo code doesn’t add up with sales on our websites. If a customer enters your code during a sale, they get your code’s discount instead of the sale price, even if the sale discount is bigger.

The discount applies only to the payment where the customer entered the code. Auto-renewals are charged at the regular price, and you still earn commission on them.

## Rules for promo codes

- Use only codes that we issued to you, or official AdGuard promotions that are publicly available.
- Use the code in the places you described in your request. For a new channel, such as an email newsletter, ask us first.
- Don’t post codes on third-party coupon or deal websites, such as RetailMeNot or Honey. A coupon website that you own is allowed after our written approval. See [Rules for coupon websites](/rules/coupon-and-deal-sites).
- Don’t show the discounted price as the regular price. Always say that it’s a discount.
- Keep codes and prices in your content up to date. Remove or replace expired codes.
- Tell your audience that you earn a commission. See [Affiliate disclosure](/rules/disclosure).

Breaking these rules can lead to a payout hold, loss of commission, or account termination. See [Prohibited practices](/rules/prohibited-practices).

## Frequently asked questions

### Do customers need to click my link if they use my promo code?

No. A sale with your code is credited to you even if the customer never clicked your link.

### Why doesn’t my AdGuard VPN code work for a 1-year subscription?

Standard AdGuard VPN codes apply only to 2-year subscriptions. Check the table at the top of this article to see which plan each code applies to.

### My promo code expired. Can you extend it?

No, expired codes can’t be extended. Request a new code in *Promo tools* → *Promo codes* and replace the old code in your content.

### Can I use my promo code in an email newsletter?

Only with our approval. Describe the newsletter in *Campaign description* when you request the code, or ask partner support before you send it.

### Does the discount apply to renewals?

No. The discount applies only to the payment where the customer entered the code. Renewals are charged at the regular price, and you earn commission on them.
